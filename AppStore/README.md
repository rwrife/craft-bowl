# Block Bowl App Store assets

Upload the PNG files in filename order from each device folder. The images are unaltered captures of the running app, converted to opaque RGB PNGs for App Store Connect.

| Folder | Device | Landscape resolution |
| --- | --- | --- |
| `screenshots/6.5-inch` | iPhone 11 Pro Max simulator | 2688 × 1242 |
| `screenshots/13-inch` | iPad Pro 13-inch (M5) simulator | 2752 × 2064 |

1. Gameplay
2. Play selection
3. Team selection
4. Roster
5. Title screen

`description.txt` contains the plain-text App Store description. Screenshots were captured from a Debug simulator build; `CBStoreScreen` launch values in the app code provide deterministic capture states.
